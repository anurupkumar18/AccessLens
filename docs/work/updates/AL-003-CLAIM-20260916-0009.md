state, shared contract, fixture reference validator, and deployed-relay source.
The current Stop path emits `session.ended`, which closes the relay even though
the controller retains the join code and permits Start again. The intended
observable behavior is a base-only `capture.stopped` event: it freezes the last
trusted student view while the temporary session remains open; only
`session.ended` and `close()` end delivery permanently. This is an additive
contract correction, not a product, privacy, or data-boundary change.
