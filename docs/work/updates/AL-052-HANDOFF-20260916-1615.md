AL-052 is handed to review and releases its claim. Found by doing something
the jsdom-based unit test suite structurally cannot do: loading the real
built `dist/` in a browser and running `axe-core` with `color-contrast`
enabled (the unit tests deliberately disable that rule, since jsdom can't
compute real layout/contrast). "Higher contrast" was producing ~1.1:1
contrast in dark mode on Live lesson, and had zero effect at all on Review
(no matching CSS rule existed). Root cause: `color`/`background` are
inherited properties resolved once and passed down as computed values, not
live `var()` references -- overriding `--ink`/`--paper` custom properties
alone does nothing for a descendant that relies on inheritance. Fixed by
combining both surfaces under one rule that explicitly redeclares `color`/
`background`, and added a static CSS test that would have caught this
(proven to fail via a real mutation, then restored).
