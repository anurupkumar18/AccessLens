T-33 addresses the extension half of the false-live gap found during AL-003 QA.
`wrapLiveRelayClient` continues to schema-drop an invalid inbound event, but now
notifies optional consumers without passing event content or parse errors.
`StudentExperience` turns that signal into a stale protocol state, preserving the
last reviewed asset/region and accessible status message. Socket reconnection does
not restore `live` from that state; only a later schema-valid event does.

This is a local extension safeguard, not deployed lifecycle proof. No shared wire
shape, capture behavior, raw media, identity, preference, analytics, or retention
behavior changed.
