# bio-cell-demo — asset provenance and review record

Every binary in this pack is original work generated by the scripts in `tools/`.
Nothing here is copied from a textbook, stock library, or third-party model
repository, so the pack carries no attribution obligation into the demo.

`tools/validate_pack.py` fails if a file under `slides/`, `models/`, or
`demo-assets/` is not listed in this table.

The typeface used to render slide text is Arial, supplied by macOS and **not**
redistributed here — only the rasterised pixels are checked in. Regenerating the
slides on a machine without Arial will fail loudly rather than substitute a
different face, because a substituted face would change the fingerprints.

## Content review

- **Status:** internally reviewed by the content workstream (Part 5) on 2026-09-15.
- **External subject-matter review:** not yet done. Implementation-plan task
  **A15** tracks review by a biology instructor and an accessibility or
  instructional-design professional.
- **Therefore:** do not describe this pack as expert-reviewed or
  accessibility-audited in the demo, the README, or the pitch until A15 closes.
  `pack.json` carries the same caveat in `review.notes`, and
  `validate_pack.py` rejects an `externalSubjectMatterReview: true` claim that
  does not name a reviewer.

Every `shortDescription` and `plainLanguage` string was written by hand in
`tools/deck.py` against introductory cell-biology material. None is generated at
run time, and the matcher never produces a description for content it did not
match — unmatched slides emit `source.unmatched` (charter invariant A9).

## Regenerating

```sh
python3 tools/generate_slides.py            # needs Pillow; rewrites slides/
python3 tools/generate_unapproved_slide.py  # needs Pillow; rewrites demo-assets/
python3 tools/generate_model.py             # standard library only
python3 tools/generate_pack.py              # standard library only; refreshes fingerprints
python3 tools/measure_matching.py           # needs Pillow; re-derives the match thresholds
python3 tools/validate_pack.py              # standard library only; must pass before merge
```

Run `generate_pack.py` after any slide change. The validator compares each
fingerprint in `pack.json` against a hash recomputed from the PNG on disk, so a
stale pack fails CI rather than silently mismatching at demo time.
